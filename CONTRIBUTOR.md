# Contributor Guide

See [CONTRIBUTING.md](CONTRIBUTING.md) for full contributing guidelines, including:
- Dual-branch development lifecycle (`dev` -> `master`)
- Local development and environment setup
- Mandatory quality gates (tests, pip-audit, Bandit SAST, build)
- Architectural and security invariants (stdio protocol safety, in-memory auth, data sanitization)
- Pull request checklist and guidelines for AI pair programmers
